### 👨‍💻 `// SOBRE MÍ`

- 🏛️ Desarrollo **sistemas en producción** para el **Gobierno Regional de Ayacucho (OTIC)**: obras públicas, asistencia biométrica, gestión documental, RR.HH. e intranet con SSO.
- 🛠️ Trabajo **de punta a punta**: APIs en **Go (Fiber / Gin + GORM)**, frontend en **Next.js / React**, apps móviles en **Flutter** y bases de datos **PostgreSQL**.
- ☸️ Llevo los sistemas a producción y los opero: **Docker, Kubernetes (k3s), ArgoCD (GitOps), Kafka, MinIO, Prometheus / Grafana** y servidores **Linux**.
- 🔐 Integro **identidad y seguridad**: Zitadel (OIDC / PKCE), JWT, API keys, RBAC y firma digital de documentos.
- 🎓 Tesis: *Implementación del sistema web SISCORE con integración biométrica multisede*.

### 🚀 `// PROYECTOS DESTACADOS`

| Proyecto | Qué hace | Stack |
|---|---|---|
| 🏗️ **[Sistema de Supervisión](https://supervision.regionayacucho.gob.pe/)** | Seguimiento de obras públicas de 11 provincias: mapa georreferenciado, expediente técnico y control de avance. **App móvil en Flutter** con mapas Mapbox, GPS, fotos de campo y asistencia. **Lideré su desarrollo.** | Go · Fiber · GORM · Next.js · Flutter · PostgreSQL · MinIO · Kafka · Prometheus |
| 🕒 **SISCORE** | Control de asistencia multisede integrado con relojes biométricos (protocolo ZKTeco iClock/ADMS implementado en Go), papeletas digitales y RBAC. **App móvil en Flutter** para teletrabajo: marcación con foto y GPS, login SSO. Base de mi tesis. | Go · Fiber · Next.js · Flutter · PostgreSQL · Kafka · S3 |
| 💾 **Réplica y backup de archivos** | Réplica de documentos institucionales entre sedes y sede central, desplegada con GitOps, con runbooks de backup y restauración y procesador de backups propio en **Rust** (MinIO → zstd → SFTP). | k3s · Kustomize · ArgoCD · Kyverno · WireGuard · MinIO · Rust · GitHub Actions |
| 🔑 **[Intranet, SSO e interoperabilidad](https://intranet.regionayacucho.gob.pe/)** | Portal único con inicio de sesión institucional, bus de eventos entre sistemas y API de interoperabilidad entre instituciones con JWT + API keys y auditoría. | Go · Zitadel OIDC · Astro · Kafka (SASL/SCRAM, ACLs) · Gin |

| 🛟 **[GLPI](https://glpi.regionayacucho.gob.pe/)** | Implementé y desplegué la mesa de ayuda e inventario de TI de la institución. | GLPI · MariaDB · Docker · Nginx |

<sub>Los sistemas corren en <b>Docker</b> detrás de <b>Traefik</b> (GLPI detrás de <b>Nginx</b>). También contribuí en <b>SIDWARI</b> (gestión documental con firma digital), <b>Escalafón</b> (RR.HH.) y el repositorio documental de <b>Recursos Naturales</b>. La mayoría de estos repositorios son privados de la institución.</sub>
